# ENG4033 - Microcontroladores - Projeto Final

## Tema

Projeto da disciplina ENG4033 - Projeto de Programação em Microcontroladores com o tema Teatro Interativo Automatizado.


## Pré-Requisitos
- Python versão 3.13
- Pygame versão - biblioteca para inteface
- Piper-TTS versão - biblioteca para a narração
- Smolagents versão - biblioteca para o agente de IA
- Pyserial versão - biblioteca para integração do python com arduíno
- ServoTimer2 - biblioteca para os servos encontrada neste [link](https://github.com/nabontra/ServoTimer2)

## Instalação
É necessário um interpretador para rodar o arquivo escrito em Python.
Usamos o VSCode como editor de código Python(.py) e a Arduino IDE para enviar o código .ino para o microcontrolador.
Configuramos o ambiente com o gerenciador de pacotes pip.
Após a instação do Python e pip digite no terminal:

```console
$pip install pygame
```
```console
$pip install piper-tts
```
```console
$pip install smolagents
```
```console
$pip install pyserial
```


## Como Usar
Clone este repositório
```console
$git clone
```

E rode o arquivo inteface.py
```console
$python interface.py
```
